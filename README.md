# Restaurant ERP Management System

A web-based Restaurant ERP Management System built to manage restaurant operations through a centralized dashboard.

## Overview

The Restaurant ERP application provides a centralized platform for managing different restaurant activities, including orders, inventory, sales, kitchen operations, expenses, and reports.

## Features

- **Dashboard:** Centralized restaurant management dashboard.
- **Point of Sale (POS):** Point of sale interface.
- **Kitchen Management:** Kitchen operations management.
- **Order Management:** Manage and track restaurant orders.
- **Inventory Management:** Manage restaurant inventory.
- **Sales Management:** Sales-related operations.
- **Expense Management:** Track restaurant expenses.
- **Billing & Reports:** Billing, invoices, and reporting modules.
- **User Management:** Manage users and roles.
- **Settings:** Restaurant configuration and preferences.

## Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS
- JavaScript
- MongoDB integration

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sneha51107/restaurant-app.git
```

### 2. Navigate to the project directory

```bash
cd restaurant-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file and add the required environment variables for your project.

Check the project configuration and database connection files for the exact variable names.

### 5. Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Production Build

```bash
npm run build
```
